# Demos

Four interactive pages, each rewritten from one of my Python projects (a Flask app, a scraper, a few
notebooks) to run in your browser. Nothing to install and no account needed. Pick one to open it.

## ISS Tracker

Where the International Space Station is right now, on a world map, with its ground track drawn in as it
moves. Updates every 5 seconds.

<span class="demo-card__tag">:material-access-point: Live data</span>
<span class="demo-card__tag">:material-map-outline: Map</span>

<span class="demo-card__tag">:material-calendar-today: Updated daily</span>
<span class="demo-card__tag">:material-console: Terminal</span>

Current temperature across all 96 metropolitan départements, as a colour-coded map. Hover or tap a

<span class="demo-card__tag">:material-access-point: Live data</span>

## Powder Diffraction Rings

Pick a crystal powder and an X-ray tube. The Debye–Scherrer rings, a detector image and a θ–2θ scan are
computed from Bragg's law as you change them.

<span class="demo-card__tag">:material-flask-outline: Physics simulation</span>
<span class="demo-card__tag">:material-tune-variant: Interactive</span>
